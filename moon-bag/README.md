# Moonbag website

The Moonbag pitch deck as a website: full-screen slides, black on white, Newsreader, animated with `motion`.

```bash
npm install
npm run dev -- -p 3001
npm run lint
npm run build
```

Design system, slide list, navigation rules and how to change things: [`docs/DESIGN.md`](docs/DESIGN.md). Repo-level notes for anyone (or any assistant) working here: [`../CLAUDE.md`](../CLAUDE.md).
